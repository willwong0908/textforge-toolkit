# 译禾工具合集 WebUI — 工作台覆盖规范

> 本文件覆盖 `../MASTER.md` 中不适用于工具型界面的通用展示页规则。

## 产品语境

- **定位：** 本地化、术语与表格处理工作台；面向需要频繁执行、核查和导出结果的 B2B 用户。
- **设计目标：** 快速扫读、低认知负担、稳定的操作反馈；避免营销页面式的大留白、夸张动效与视觉噪音。

## 布局

- 桌面：236px 固定侧栏 + 自适应内容区；内容最大宽度 1480px。
- 内容区：桌面 `40px` 水平内边距，平板 `20px`，手机 `14px`。
- 使用 8pt 间距：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56px。
- 首页工具入口使用 6 列 Bento 网格：文本预处理和 Diff 各占 3 列；AI 审校占 4 列；跨 Excel 占 2 列。窄屏改为 2 列和单列。

## 排版

- 优先使用本地系统字体：`Inter, Microsoft YaHei UI, Segoe UI, Arial, sans-serif`；不依赖在线字体加载。
- Hero：26–34px / 760；Section：20–22px / 720；Card：17px / 760；Body：14px / 400；Caption：11–12px / 650。
- 数值、端口、文件指针使用 `Cascadia Mono` 或 `Consolas`。

## 组件规则

- 卡片、输入框、按钮使用 1px 实线边框；圆角只使用 6 / 8 / 12px。
- 常规面板不使用阴影；只允许模态框、下拉面板使用一层低透明度浮层阴影。
- 所有可点击元素：`cursor: pointer`、150–200ms 的颜色/边框过渡；禁止缩放和位移造成布局跳动。
- 主按钮为纯蓝色，不使用绿色或青色渐变；次按钮使用白底细边框。
- 导航激活态为浅蓝底 + 蓝色文字；状态由文字和边框/色彩共同传达。
- Banner 使用信息图标、细边框与淡色背景，不伪装成大卡片。

## 可访问性

- 交互元素统一提供 2px 蓝色 Focus Ring 与 4px 低透明外扩环。
- 页面提供“跳到主内容”链接；Tab 顺序与视觉顺序一致。
- 在 `prefers-reduced-motion: reduce` 下关闭过渡和动画。
- 最小视口 375px 不得产生横向滚动。

## 明确避免

- 大面积高斯模糊、玻璃拟态和多层弥散阴影。
- 大圆角白色营销卡、无描述的大按钮、泛绿/泛青渐变。
- 用颜色作为唯一状态表达，或没有 Hover / Focus 状态的可点击区域。
