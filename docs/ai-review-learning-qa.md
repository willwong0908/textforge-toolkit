# AI 审校缓存与自主学习验收记录

日期：2026-09-11。实施前回滚快照：`95b40bc`；规范编辑与学习进度补充快照：`d001377`。本次未打包、发布或新增遥测。

## 已实现

- 设置页“审校设置”新增默认开启的审校缓存、自主学习开关；独立持久化。
- Session 无问题缓存、反馈事件、正文及候补规范分别存储；删除会话清理，并阻止学习响应晚到后重新写入。
- 缓存批量查询；匹配语言、文本、上下文、模型、提示词、术语内容等。memory 更新不改变缓存键。
- 本地术语表使用文件内容指纹；memoQ 使用实时资源元数据指纹及条目命中的术语内容（包含备注），不只比较名称。未使用 memoQ 列表的五分钟缓存判断版本；服务不提供更新字段时，实际命中术语内容仍参与匹配。
- memoQ 查询覆盖全部原文，每组最多 32 段；当前审校批次仅携带相关术语，避免向每包发送全文件术语集合。
- 详情忽略为临时草稿，关闭取消、确定提交；反馈原始证据保留。Excel 增加下拉反馈、原因、整行条件颜色和隐藏身份标识。
- Excel 排序后可回传，重复上传不重复学习；拒绝跨会话、篡改原译文、缺失标识及无效选择。
- 学习采用一次反馈一次模型请求：首次创建、随后携带旧正文和候补；程序计算权重，按约 3000 字预算选择完整规则。
- 失败保留人工决定和旧 memory，可重试学习或导出；同 Session 串行处理。每次反馈重新生成版本化结果文件并更新任务输出链接，不覆盖已打开的旧文件。
- 请求、响应、记忆版本和权重变化写入既有本地日志，不把模型凭证加入学习载荷。
- 会话输入区可打开规范编辑器，分别查看使用中和候补规范、权重及版本；允许修改规范文字。保存时校验 memory 版本，避免覆盖同时完成的后台学习。
- 反馈保存、反馈文件上传、学习排队、模型处理中、完成和失败均显示进度与明确状态；失败入口继续提供重试。

实际操作：

1. 关闭两个设置开关、保存、刷新，确认仍关闭；再开启保存。
2. 上传 Excel，打开文件导入和手动映射编辑窗口，再走 AI 识别、确认、双语种审校、结果详情。
3. 输入忽略原因、点击忽略置灰、点击 ×；再次打开后勾选和原因均清空，结果未修改。
4. 忽略并确认，更新结果及 Excel，产生 memory v1。
5. 点击“上传优化文件”，通过文件选择器上传反馈 Excel，产生 memory v2。
6. 同会话重新上传原始 Excel：日语结果缓存命中 **2 条、请求 0 条**；尚未忽略的中文结果 **请求 2 条**。新任务固定使用 memory v2。
7. 打开追问并发送、切换目标语言、打开术语库菜单和主设置页；交互正常。
8. 检查宽屏和 1280×900 布局；修正原因框与旧追问按钮绝对定位重叠，以及新增缓存文字挤换进度条的问题。最终页面无 JavaScript console error。
9. 点击“查看规范”，确认使用中/候补分组、权重和版本可见；修改规范并保存，memory 从 v2 更新为 v3，重新打开后内容保持。
10. 分别验证完成状态 100% 与模型处理中状态 68%；进度条、状态文案和规范按钮同时可见。
